# Hospital Management System

A dynamic web application designed to enable full CRUD (Create, Read, Update, Delete) operations for comprehensive hospital data management. This system allows efficient management of doctors, patients, and appointments.

## 🏥 Features

- **Doctor Management**
  - Add, view, update, and delete doctor records
  - Track doctor specializations and contact information
  - Manage doctor availability and schedules

- **Patient Management**
  - Create and maintain patient profiles
  - Store patient medical history and personal information
  - Update and delete patient records
  - View complete patient details

- **Appointment Management**
  - Schedule appointments between patients and doctors
  - View all appointments
  - Update appointment details
  - Cancel appointments

## 💻 Technology Stack

- **Backend**: Java
- **Frontend**: HTML
- **Architecture**: Web Application with full CRUD operations

## 📋 Prerequisites

- Java Development Kit (JDK 8 or higher)
- Web browser (Chrome, Firefox, Safari, or Edge)
- Database system (as per your configuration)

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sumitgourdlp2/Hospital-Management-System.git
cd Hospital-Management-System
```

2. Compile the Java source files:
```bash
javac src/*.java
```

3. Run the application:
```bash
src/main/webapp/signup.html
```
Deploy on Apache Tomcat Server

### Configuration

1. Configure your database connection in the application settings
2. Update any necessary configuration files with your database credentials
3. Ensure all dependencies are properly installed

## 🔧 Usage

### Adding a Doctor
1. Navigate to the Doctor Management section
2. Click "Add New Doctor"
3. Fill in the doctor's details (name, specialization, contact info)
4. Submit the form

### Adding a Patient
1. Go to Patient Management
2. Click "Add New Patient"
3. Enter patient information (name, age, medical history, etc.)
4. Save the patient record

### Scheduling an Appointment
1. Access the Appointment section
2. Select a patient and available doctor
3. Choose preferred date and time
4. Confirm the appointment

## 📝 CRUD Operations

### Create
- Add new doctors, patients, and appointments

### Read
- View all records in the system
- Search for specific doctors, patients, or appointments

### Update
- Modify existing doctor, patient, and appointment information

### Delete
- Remove records from the system (with appropriate confirmations)
